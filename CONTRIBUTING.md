# Contributing

Suggestions for new papers, corrections, and official implementation links are welcome. [Open an issue](https://github.com/Collab-Gen/Awesome-sparse-attention-for-visual-generation/issues/new/choose) or submit a pull request against `main`.

## Adding a paper

1. Search [README.md](README.md) by title and arXiv ID or DOI. If a journal or conference version supersedes a preprint, update the existing entry and its appearances in the application index.
2. Include the published title, bibliographic year, and a link to the paper. Include the official code or project link when available.
3. Suggest where the work fits in the [4+1+3 framework](README.md#the-413-framework) and give one sentence explaining the connection. For instance, a calibrated template belongs under [static sparse attention](README.md#static-sparse-attention) when its retained connections are independent of the runtime sample.
4. Add a task entry under [Applications](README.md#applications) when the paper demonstrates a relevant visual-generation application. Papers from related domains can go under [Additional references](README.md#additional-references) when their method or execution design transfers to visual generation.

Use the existing format for the section. In paper tables, put newer entries first by bibliographic year. Within the same year, use the arXiv identifier or the publication month. A paper may appear in more than one section when each appearance helps readers find it by a different mechanism or task.

## Correcting an entry

Point to the affected section and include a primary source, such as the paper, proceedings page, or authors’ repository. For a classification change, identify the relevant figure, section, or experiment in the paper.
